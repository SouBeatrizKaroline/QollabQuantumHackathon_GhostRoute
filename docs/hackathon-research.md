| Decision | Purpose |
| --- | --- |
| Static browser frontend | Play without installing a quantum runtime. |
| Separate Python/Qollab execution | Inspectable circuits and explicit run evidence. |
| Visible GHZ ambiguity | Show the tradeoff rather than promise automatic positioning. |
| Stable campaign formations | Gradual difficulty in familiar geometry. |
| 64 ship views and walkie-talkie | Smoother steering, upright mast and messages clear of the helm. |
| Four complete documentation languages | English first, with full access in each supported language. |
| Generated packages | Distribute canonical sources without maintaining duplicated code. |

The contribution is their integration into a rescue game; the team does not claim to have invented Ramsey interferometry, GHZ states or Bayesian localization.
