# Submission checklist

**English** · [Português (Brasil)](pt-BR/submission-checklist.md) · [Português (Portugal)](pt-PT/submission-checklist.md) · [Español](es/submission-checklist.md)

Collect actual evidence. A playable browser game, local circuit tools and platform publication are separate deliverables.

- [ ] Review current official process and terms: eligibility, deadline and prior-work disclosure.
- [ ] Confirm the captain’s registration and account access.
- [ ] Confirm source visibility, MIT license, dependencies and signed-out access wherever required.
- [ ] Generate the package with python scripts/package_qollab.py; preserve root main.py, sensor.py and requirements.txt.
- [ ] Follow the current runtime workflow, select an appropriate permitted backend and run the entry point.
- [ ] Save the real project URL, backend identification and execution result.
- [ ] Show the combined eight-qubit circuit in one backend job; distinguish it from local replay and browser sampling.
- [ ] Adapt the project overview with actual playable, platform and video links.
- [ ] Record the 2–3 minute demo using actual scores and results; verify public links without sign-in.
- [ ] Confirm AI/visual-reference credits and contribution chronology with the team.
- [ ] Preserve the exact attribution below.
- [ ] Submit through the registered account and retain platform confirmation.

Local tests do not replace run, video or submission evidence. Check official requirements at submission time; this page does not freeze a deadline or claim live account status.
