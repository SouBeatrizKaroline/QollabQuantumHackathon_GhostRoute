| Decisão | Objetivo |
| --- | --- |
| Frontend estático | Jogar sem instalar um ambiente quântico. |
| Execução Python/Qollab separada | Circuitos inspecionáveis e evidência explícita de execução. |
| Ambiguidade GHZ visível | Mostrar a escolha envolvida, sem prometer uma posição automática. |
| Formações estáveis de campanha | Dificuldade gradual numa geometria familiar. |
| 64 vistas e walkie-talkie | Giro mais suave, mastro na vertical e mensagens sem cobrir o leme. |
| Quatro idiomas completos | Inglês como principal, com acesso completo em cada idioma. |
| Pacotes gerados | Distribuir as fontes oficiais do projeto sem manter código duplicado. |

Tema pretendido: Quantum Playground. O protótipo não afirma precisão operacional nem vantagem quântica demonstrada sobre uma referência clássica forte.
