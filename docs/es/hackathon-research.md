Comprueba las reglas actuales al publicar o presentar. Los enlaces no acreditan acciones de cuenta ni ejecuciones de backend. Los plazos, visibilidad y recuentos antiguos se eliminaron de las guías actuales.

| Decisión | Objetivo |
| --- | --- |
| Frontend estático | Jugar sin instalar un entorno cuántico. |
| Ejecución Python/Qollab separada | Circuitos inspeccionables y pruebas explícitas de ejecución. |
| Ambigüedad GHZ visible | Mostrar la decisión implicada sin prometer posición automática. |
| Formaciones estables de campaña | Dificultad gradual en una geometría familiar. |
| 64 vistas y walkie-talkie | Giro más suave, mástil vertical y mensajes sin cubrir el timón. |
| Cuatro idiomas completos | Inglés como principal, con acceso completo en cada idioma. |
| Paquetes generados | Distribuir las fuentes oficiales sin mantener código duplicado. |

Ghost Route se basa en técnicas reales de sensado y navegación cuántica, en una versión educativa y simplificada. El equipo las investigó a partir de la noticia de Q-CTRL.
